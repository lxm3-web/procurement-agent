# handle — 處理一筆異常（從判斷到詢價信）

輸入：料號（＋通知裡的延遲天數與原因）。

1. `scripts/fetch_data.sh`（若 detect 剛跑過可略）
2. 依 `knowledge/02` 算四個數字：撐幾天、需求量、備援可供、缺口；定風險等級、要誰核准；列出觸發的規則（只看 R001–R010）
3. 依 `knowledge/03` 排序備援供應商、決定向誰要多少、需求日
4. 依 `knowledge/04` 寫詢價信到 `outbox/`，一家一封；**缺口 > 0 再多寫一封交期協調信給業務**；每封最上面 `> 狀態：待確認`
5. `log/incident_log.md` 加一列（欄位見該檔表頭），人工確認欄先寫「待確認」
6. 依 `knowledge/05` 三行交件

- 不准寄信、不准改 Sheet
- 資料缺就停下來問，不補數字
