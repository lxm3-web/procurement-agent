# 04 信件範本（詢價信＋交期協調信）

檔名：`outbox/YYYY-MM-DD_料號_詢價信_供應商名.md`。一家一封。

```
收件：{vendor_name} 業務窗口
主旨：【急件】{material_code} {material_name} 緊急採購詢價 — {數量} 件

{vendor_name} 您好：

我們是{公司名，示範寫「XX 網通」}採購部。因原供應商交期異動，急需補料如下，請於今日內回覆報價與可交期：

料號／品名：{material_code} {material_name}
數量：{數量} 件
需求到廠日：{需求日}
交貨地點：本公司廠區
付款條件：依既有合約

若無法一次到貨，請提供分批交期。有任何問題請直接回信或來電。

謝謝。

採購部 {承辦人}
{日期}
```

## 規則
- 一封信一個料號、一個供應商，不合併
- 數字只能來自 `03` 算出來的量，不四捨五入
- 不寫「非常緊急請務必」這類施壓語，一個「急件」就夠
- 不提原供應商名字與延遲原因（那是我們內部的事）
- 信寫完，最上面加一行 `> 狀態：待確認`，人確認後改成 `> 狀態：已寄 YYYY-MM-DD HH:MM`

# 交期協調信（給業務）— 只在「缺口 > 0」時多寫這一封

檔名：`outbox/YYYY-MM-DD_料號_交期協調_業務{姓名}.md`

```
收件：業務部 {業務姓名}
副本：採購部 {採購主管}
主旨：{material_code} {material_name} 斷料 — 請協調 {客戶} {N} 張訂單分批出貨

{業務姓名}：

{原供應商}今早通知 {material_code}（{material_name}）延後 {delay_days} 天。目前庫存只撐 {days_remaining} 天，備援供應商合計只能補 {available_qty} 件，需求 {required_qty} 件，缺口 {shortage} 件。

受影響訂單：
- {order_id} {customer} {quantity} 件（依 production_date 排）

請你跟 {客戶} 談：
1. 先出 {available_qty} 件（備援料 {最短交期}–{最長交期} 天可到廠），優先給 {最早那張}
2. 其餘 {shortage} 件配合原供應商 {預計出貨} 後補
3. 若客戶不接受分批，請回報，採購會再找第三家

詢價信已寄出，供應商回覆後我再更新交期。

採購部 {承辦人}
{日期}
```
規則：數字全部來自 02／03 算出來的；這封信可以提原供應商名字（內部信）。
